# ⌨️ TypeCraft - タイピング練習 Webアプリケーション

日常ローマ字（ふりがな付き・柔軟入力）、実用英単語、プログラミング構文の打鍵速度（WPM）と正確率を測定し、初心者から名人までの段級位・称号を評価するシングルファイルWebツールです。  
外部サーバーへのデータ通信を行わず、すべてお使いの端末（ブラウザ）内のみで完結して動作します。

> **🚀 Live Demo:**  
> ブラウザで今すぐ練習できる本番公開版はこちら 👉 **[https://selfup.net/typing/](https://selfup.net/typing/)**

---

## 🌟 主な機能 (Features)

### 1. 柔軟な日本語ローマ字パーサー
- **「ん」の1打確定:** 次の文字が子音なら `n` 1回で自動確定し、スムーズに後続へ連動（`nn` の2度打ちにも完全対応）。
- **入力ゆらぎの即時適応:** 「ち（`ti`/`chi`）」「し（`si`/`shi`）」「つ（`tu`/`tsu`）」「ふ（`fu`/`hu`）」「じ（`zi`/`ji`）」「しゃ（`sya`/`sha`）」など、打ったキーに合わせて表示と判定がリアルタイムに追従。
- **ふりがな（ひらがな）連動:** 漢字のお題にふりがなガイドが付き、入力進捗に合わせて色分け表示。

### 2. JIS日本語配列オンスクリーンキーボード
- 日本の一般的なJISキーボード（106/109キー）レイアウトを採用。
- 次に打つべきキーが光る運指ガイド機能を搭載（ブラインドタッチ練習用の「非表示」切り替えも可能）。

### 3. 3つの実践コース & 称号評価システム
- **コース:** 日本語ローマ字（短文・ことわざ等） / 英単語（NGSL語彙・名言） / プログラミング（JS/Python）
- **段級位評価:** 完走時のWPMと正確率に基づき、「名人（ゴッドハンド）」「達人」「上級」「中級」「初級」「初心者」を自動判定。

### 4. 快適な打鍵フィードバック
- **Web Audio API 内蔵シンセ:** 音声ファイル不要で心地よい打鍵音とミス警告音をリアルタイム生成（ミュート可）。
- **ユーザー設定の自動保存:** 大文字・小文字の完全一致要否、スペースキー打鍵の要否、キーボード表示状態をブラウザに自動記憶。
